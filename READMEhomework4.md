REFLECTION---
When running my website through the WAVE accessibility checker, it helped me understand that a website can look good to me but still create problems for other users, such as someone with eyesight trouble. WAVE found several contrast errors on my website. These errors were caused by text colors that did not have enough contrast with their backgrounds. I corrected these issues by changing the colors in my CSS file so the text would stand out more clearly against the background. Before this assignment, I mostly chose colors based on how I wanted my website to look. I did not realize how much the difference between the text and background colors could affect accessibility. Low contrast can make a website difficult to read for people with low vision or color-vision difficulties. After making my changes, I tested the website again with WAVE to make sure the problems were corrected. I learned that accessibility should be considered while designing a website instead of only checking it after the website is finished.
